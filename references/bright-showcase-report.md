# 明亮样片交付记录

2026-10-12。用户要求横竖版都交付，视觉更鲜活，配色与题材更多变，并可以在 GitHub 展示。本轮完成三组原创动画，共六条实际 MP4，同时提供从编码成片生成的 GIF 和封面。

| 样片 | 视觉与内容 | 横竖构图 |
| --- | --- | --- |
| 柠檬汽水 | boing-candy 的棉粉、薄荷、柠檬黄。挤汁、开环、喷泡、弹性落地 | 横版左文右产品；竖版上部阅读、中下部产品，独立画幅位置 |
| 让点子飞 | sticker-club 的奶油白、钴蓝、樱桃红、明黄。真实纸面折叠、曲线飞行、模切贴纸与创意印记 | 独立 Bezier 轨迹、纸面尺寸与贴纸位置 |
| 花开有声 | 明亮矿彩纸面、石青、石绿、朱砂、土金。种子萌芽、莲瓣展开、藻井纹样汇聚 | 横版左字右花；竖版上字下花，引线单独重绘 |

每条 16 秒、30 fps、480 帧。六条合计 96 秒、2880 编码帧。每个帧使用单次实际浏览器采集，避免将旧 Forge 三曝光的计数和验收混入本轮。原有严格 Studio 引擎未改变，本次是可编辑的独立 Remotion 自由创作路线。

三支配乐分别为明快 mallet pop、拨弦轻鼓、五声音阶与柔和敲击。各自为 120 BPM、8 小节、16 秒，使用原创编排与程序化音色。汽水、纸飞机、矿彩分别有 221、219、203 个音乐及动作音事件。每个主题的横竖版使用相同字节的 48 kHz、双声道 PCM16 原创 WAV。

## 返工记录

| 实际问题 | 处理 |
| --- | --- |
| Paper v1 竖版黄章压住介绍句 | 实际原分辨率帧发现，黄章下移，保留动作最大放大和上抬空间。仅画幅 bounds 检查没有抓到图形遮字，因此额外实际视审仍必要 |
| Paper v1 起飞尺寸瞬间缩小 | 沿 launch 区间连续插值，保持同一纸面实体 |
| Mineral v1 前两秒主要画引线 | 主茎从种子位置真正伸长，第一片叶提前至 0.75 秒启动；最终实际 1 秒帧可见萌芽 |
| Citrus 首版结尾空等 | 增加同一罐口的末次喷泡、短跃和落地，14.5 秒结束，保留 1.5 秒稳定结尾 |
| Citrus R1 英文尾字粘连徽章 | 独立实际编码帧发现，记录 `needs-work`。英文左移并缩小，重新渲染全部六片为 R2；新审确认完整字形和间距 |
| 发布检查可以删掉源码键 | 改为独立枚举并严格核对完整源集合，不能使用空 map 冒充当前源绑定 |
| Python 优化模式跳过 assert | 改为显式 `require`，优化模式对错误 schema、空批次和缺项同样拒绝 |

R1 视频、失败和旧审阅报告在交付工作区保留。R2 矿彩 MP4 与部分编码 PNG 不同于 R1，因此进行全新的 R2 抽样视审，没有以相同 DOM 记录推定相同像素。公开 [清单](bright-showcase-status.json)仅引用当前 R2；所有技术、抽样视觉与自动播放结果均独立于用户审美批准。

## 展示与边界

[六片动态画廊](../demos/bright-showcase/README.md)提供六条静音 10 fps GIF，点击打开 30 fps 带声音 MP4。封面来自最终成片编码帧，没有用单独设计的图代替影片。源码和复现命令见 [showcase](../showcase/README.md)。

人工完整观看与听审尚未完成，声音测量不表示好听或视听节奏已由人批准。样片展示三种原创视觉与内容机制，不表示新主题已接入旧严格 JSON 枚举，也不表示已验证任意题材的自动制作。GitHub CI 另渲染横版 Citrus 夹具，以实际产物检查新入口，不能替代本地全部六片或人工审美。
