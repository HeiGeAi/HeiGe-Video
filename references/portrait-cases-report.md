# 四条竖版案例交付记录

2026-10-12，当前批次为 `final-r2`。四条实际视频均为 1080×1920、9:16、30 fps、16 秒，共 64 秒、1920 个编码帧。

| 案例 | 具体动作 | 原创配乐 |
| :--- | :--- | :--- |
| 莓好一口 | 草莓入碗、混合、三球叠起、开盖淋酱、彩糖与顶饰落定 | 120 BPM 摇摆马林巴 |
| 咖啡醒醒 | 手柄锁入、双股萃取接杯、奶涡转叶纹、蒸汽 | 96 BPM 爵士电钢与轻刷鼓 |
| 快乐开拍 | 旋钮、伸镜、快门、同一照片连续吐出与显影 | 120 BPM 切分 funk |
| 小宇宙发射 | 零件装配、支架撤开、点火、曲线起飞、行星前后绕行 | 150 BPM 太空琶音 |

所有场景、产品与配乐均为原创概念演示。没有使用外部生成模型、采样包或参考旋律。两套字体是保留来源和 OFL 许可的重命名子集。

## 实际检查范围

- 每片完整 480 帧视频解码，尺寸、帧率、时长与媒体合同通过。每片 480 个生产 DOM 文本边界和本地字体就绪记录完整，零 frame bounds errors。边界检测不能代替遮挡或字形检查。
- 每片绑定当前完整 20 项执行源文件，以及 30 项实际产物，共核对 120 项产物 hash。字体、依赖、配乐及媒体检查器均在源图内。
- 独立编码画面审阅：Berry 19 帧、Coffee 31 帧，Camera 的 15 张标准编码原图及关键追加样本。Rocket 的 R2 MP4 与 R1 及全部 30 项产物逐字节相同，重新核对当前源图并新鲜查看飞行避让关键帧。每片 15 张标准 PNG 与从对应最终 MP4 独立重新解码的 RGB 完全一致。
- 四条原始配乐共 855 个事件、52 个动作 cue，所有事件使用最近采样点 `Math.round(at * 48000)`。在构建使用的 Node 24.19.0 下，完整 metadata、events、WAV、PCM 均独立重合成相同。
- 四片实际 AAC 保留原始 48 kHz、双声道完整解码，每声道 768000 个样本、16 秒。每声道有限、非静音，未观察到 sample overs。没有下混测峰。
- Chrome 155 以 1 倍速、静音，从零连续播放到结束。每片 decoded 与 presented 均 480 帧，观察到的 dropped frames 为零。该结果不是人工观看或听审。
- 四套 heige-design 设定集 lint 均为零 error、零 warning，只确认设定规范，不是成片审美认证。
- 发布清单校验在 Python 优化模式下仍通过；隔离副本中，空 source map、失真 AAC 声明、2 倍速与丢帧声明、重绑定 hash 的满幅左声道加静音右声道均被拒绝。这是清单和真实 PCM 检查，不是重新渲染或听审。

完整人工观看、实际听音及用户对新四片的审美认可尚未完成，状态保持 `not-tested`。

## 修复与保留记录

首次 proof 的咖啡流被杯沿截断，修为在杯体之后绘制并接同一液面涟漪。火箭右上装饰星影响舷窗避让，移除该装饰。冰淇淋入口与跃起峰值重新留出字幕净距。R1 成片的 Food 底部署名短暂与入场物体交叠，R2 让署名在 1 至 1.25 秒出现，重新编码复核无交叠。

所有旧 proof、R1 needs-work 报告和音频比较失败记录均保留在本机输出目录，没有把失败改写为通过。Node 22 与 24 的两个中间浮点字段曾有约 1e-15 差异，WAV 和事件字节一致；按构建 Node 24 复查完整 metadata 后精确相同，未放宽阈值。不同浏览器和编码运行不保证视频逐位相同；Camera R2 实际编码画面有变化，已经重新审阅。

本批次独立位于 `portrait-cases/`，原有 `showcase/`、严格 Studio 引擎及此前六条明亮成片的源与媒体不变。原六片完整清单仍通过当前校验。
