# HeiGe Video v2-RC implementation and acceptance status

This is a source-level portable release candidate: five distinct director packs, one shared SVG/Canvas runtime, and authored examples. It does not establish that every coding agent or low-cost model reaches any named model's visual quality. The current per-source hashes and evidence levels are in [example-status.json](example-status.json); historical runtime/package tests are in [validation.json](validation.json). Public-release checks and the verified original demo inventory are in [release-validation.json](release-validation.json) and [demos](../demos/README.md).

Record three levels separately: source draft, technical continuous pass, and director acceptance with exact review scope. Here, acceptance is sampled-image/targeted review; none of these statuses implies full real-time playback approval. Optional original sound sketches exist for four 30-second examples; audio has been measured, not listened to. Dataviz deliberately has no audio track.

The example modules retain some historical standalone preview/export helpers. Use the packaged runtime commands. Versioned hashes and evidence determine acceptance, not an old comment, a filename containing “final”, or a successful encode.

## Research evidence boundary

The supplied 58-work baseline reports 51 useful mechanism references and seven controls/negative examples, deduplicated across 11 authors or publishers. Same-topic model/language variants count as one creative work; one failed download was excluded.

That baseline reports 3,053.900 seconds of source footage, 108,878 decoded source frames, 338 full-domain/dense contact sheets actually inspected plus 24 supplemental images. Inspection used roughly one-second source-frame coverage, final frames and selected dense actions. This is not every frame individually viewed, every film played in realtime, or audio heard. This Skill integration did not redo the complete reference audit.

The earlier eight-reference study and 33-project documentation screening are earlier/subset work, not additional films to add to 58. A useful reference can still have readability, factual or material defects. The portable ledger distributes source links and observations, not private evidence paths, reference footage or asset rights.

## Model and forward-test boundary

Author labels on public videos are attributed provenance, not independently verified model execution. The original dataviz forward application succeeded after repairs with an available coding/review workflow; its exact model identifier was not exposed and remains unknown. It is one exploratory application, not a controlled low-cost-model test, universal-agent certification or parity evidence. A bare text API still needs an execution harness and actual visual reviewer.

No low-cost GPT/DeepSeek API comparison or cost advantage was measured in this work. A later benchmark must use real authorized calls and the separate [benchmark protocol](benchmark.md).
