# v3.0.0-rc.1 verification status · 2026-10-06

HeiGe Video v3.0.0-rc.1 is a prerelease candidate. Do not confuse a source candidate, a technical render, sampled visual review, full-speed playback and listening.

Public-package regression evidence is recorded in [v3 release validation](v3-release-validation.json). The earlier candidate receipt is historical evidence for its recorded hashes, not a checksum manifest for updated release documentation.

## Current implementation

- Canvas/SVG runner, authored Canvas duration/readiness/state metadata, declared glyph checks, hard-cut metadata and shared motion helpers are implemented
- Optional cut-aware linear-light Canvas shutter sampling and decoded MP4 action/cut strips are implemented
- After core document/research integration, 40 runtime tests and 27 script tests passed. Package validation passed with 100 video and 100 project records. The [candidate core validation receipt](candidate-validation.json) records the tested revision scope; later source edits need fresh checks
- The portable research corpus contains 100 distinct media hashes/URLs and 100 distinct canonical repositories. Metadata, categories, rights/coverage fields and uniqueness are structurally validated
- A small offline selector returns relevant mechanisms and caveats, with controls excluded by default

## Research scope

100 works comprise 79 mechanism references, 3 case-study/tutorial references, 1 mixed reference and 17 controls. 51 baseline works were freshly reinspected and 49 are new. Each record states decoded-frame coverage, selected dense samples and source hashes. Coverage is not uniform; longer works can have sparse overview samples. All-source-frame viewing, complete realtime playback and audio listening were not performed.

100 canonical repositories comprise 50 agent/authoring projects and 50 rendering/motion/QA projects. Targeted source paths were inspected. Instruction/specification skills are labelled; the count does not imply 100 rendering engines. Third-party projects were not installed, built, executed or runtime-validated by the source audit. Public demo links and author model labels do not prove execution or provenance.

No reference movies, image frames, third-party source snapshots, fonts or music are included in the research corpus. Source-code licenses do not automatically license media.

## Experimental and unverified

- Browser adapter: separate experimental route, locally blocked by a Unix-socket permission error; no verified browser film output
- Blender: CPU probe succeeded, but no general full-film pipeline is shipped or selected by default
- Automatic layout/semantic/factual checks, dependency-aware partial rendering and model-driven audio assembly: research proposals, not shipped guarantees
- No controlled model benchmark, paid API comparison, cost advantage or Opus parity has been established
