# Sources and research method

The v3 corpus has two separate units. Do not add them together as films or describe them all as renderers:

- [100 distinct works](research-cases.md), with [JSON coverage ledger](research-cases.json): decoded-frame observations, selected dense intervals, source/media URLs, hashes, transfer ideas, defects and rights uncertainty
- [100 canonical repositories](research-projects.md), with [JSON source ledger](research-projects.json): agent systems, authoring/specification skills, renderers, motion libraries and QA tools, with inspected code paths and qualified licenses

The video corpus contains 51 freshly reinspected baseline works and 49 new works. Media URL/hash uniqueness is checked independently of titles or portfolio pages. Cases include 79 mechanism references, 3 case-study/tutorial references, 1 mixed reference and 17 controls. Sampling density differs per work; the ledger retains exact timestamps. Full realtime playback, actual audio listening and every-source-frame inspection were not performed.

Project source inspection is separate from demo inspection. No third-party project was installed, built, executed or runtime-tested by this source audit. Some projects implement prompt/specification workflows rather than code engines; their maturity notes preserve that distinction. Public repositories with missing or custom licenses are not treated as automatically reusable code.

Study mechanisms such as persistent object state, final-composition planning, absolute-time evaluation, shared event clocks, material-driven movement and decoded-pixel review. Reimplement appropriately in original work. Do not copy reference characters, brand screens, master images, music or fonts merely because the source engine is permissively licensed.

[Upgrade mechanisms](upgrade-mechanisms.md) explains what was applied and what remains a proposal. [Source notices](source-notices.md) preserves the existing project and research attributions. Author model claims are not independently verified generation evidence; no cost or model-parity test is established here.
