## 本次实际得到的产品能力

研究固定在 [OneTake 提交 2f5fbd3](https://github.com/feitangyuan/onetake/tree/2f5fbd363a0aec22055fbf62489380065737c91d)。本项目保留 BrewReel 研究后建立的受控内容、事实、声音时钟与交付契约，再用原创实现加入连续世界。[架构研究](onetake-architecture.md) 标明集成前快照与当前实现，[质量研究](onetake-quality.md) 保留实际反例，[融合说明](onetake-integration.md) 映射方法与模块。

| 产品能力 | 当前落地 |
| --- | --- |
| 原生创作入口 | `init` 按三种画幅创建可编辑 JSON，复用 validate、build 与 verify；初始化拒绝覆盖 |
| 持久世界 | 稳定对象 ID 与语义身份声明，完整轨迹、统一全局相机和原生 beat 时间段 |
| 跨镜承接 | 每对相邻 beat 声明 carrier、cause、outcome；从实际浏览器 DOM 测量对象、可见性与形变 |
| 真实时间曝光 | 每个编码帧取三个真实浏览器时刻，180° 快门，线性光合成；可关闭为单采样 |
| 动作声音 | 原创 tick、whoosh、impact，以相同事件时码和屏幕位置生成双声道材料，再进入混音与限幅 |
| 可核对成片 | 最终 MP4 完整解码、逐帧 DOM、字体与布局、承接条带、输入与引擎及产物哈希 |

没有搬入上游源码、模板、字体或媒体。没有训练模型或内置在线 LLM、TTS、ASR、生成供应器、自动网站重建。当前主要交付是 coding agent 可使用的原生视频生产系统。

## 三种比例的真实成片

三条均为 16 秒、30 fps，共 48 秒、1,440 个编码帧。各自构建捕获 1,440 次实际浏览器曝光，共 4,320 次。全部使用当前引擎，逐帧 DOM、最终像素与报告一致，三个承接边界分别通过。

| 成片 | 尺寸 | build＋verify | Chrome 完整静音播放 | 独立编码抽帧 |
| --- | --- | --- | --- | --- |
| [横版](../demos/continuous/horizontal.mp4) | 1280×720 | 通过 | 480 帧呈现，0 丢帧 | sampled-pass |
| [竖版](../demos/continuous/portrait.mp4) | 720×1280 | 通过 | 480 帧呈现，0 丢帧 | sampled-pass |
| [方版](../demos/continuous/square.mp4) | 1080×1080 | 通过 | 480 帧呈现，0 丢帧 | sampled-pass |

系统 Google Chrome `155.0.8059.39` 自动从 0 按正常速度播放至 ended，持续静音，无视频或页面错误。实际浏览器呈现不等于完整人工观看或实际听音。每条独立视觉检查包括 25 格总览、三个边界共 48 格条带和 18 张满分辨率帧。横版 MP4 与已审 v2 同字节，当前引擎与输入重新核验，全部帧重新解码，视审记录明确绑定相同像素。

音频测量保留全部声道，峰值约 0.227 至 0.234，时长均 16 秒，RMS 与有限数检查通过。峰值是解码样本峰值，没有宣称完成 true peak、LUFS 或人类听感批准。每条实际听音为 `not-tested`。

三曝光原始 PNG 为临时文件，合成后已删除。逐曝光与合成哈希可核对记录，没有据此宣称能够重新合成已删除源图。点阵遮挡和 96×54 灰度差都有空间盲区；3 至 9 秒的工作面板为机制示例阅读保持，不能证明商业宣传的节奏质量。

## 本次实际失败及修复

| 实际发现 | 处理与复核 |
| --- | --- |
| 首次全量 Node 测试 3 项失败，中文字体环境未正确指定，未到达预期权限拒绝点 | 明确使用本地字体与实际 Python 环境，完整重跑；失败日志保留 |
| 首条调试成片末承接尺度变化不足，触发 STATIC_CARRIER | 修改实际承接几何并重新渲染，保留 rejected MP4 |
| 首轮竖版在承接窗口的点阵可见率 0.48，低于 0.50 | 提前淡出退出文字，重新构建并 verify；没有直接放松阈值 |
| 修正后竖版技术通过，独立视审发现「看得清连得」「上」孤字与面板外文案 | 拒绝该视审结果，加高竖版面板并明确两行各三个字，三比例全部使用最终代码重渲 |
| 自动布局未表达文字与独立面板的包含关系 | 真实生产组件、CSS、字体转换和 Chrome 逐字 Range 回归；新稿通过，旧 220 高面板与旧文案复原后必须失败 |
| 任一声道峰值可能被单声道下混掩盖 | 最终音轨按全部声道检查，混音加入限幅；实际 PCM 反例回归 |
| 抽样静帧之间出现文字碰撞 | 每帧实际中间曝光同时检查全局文字几何，真实浏览器反例可拒绝 |
| 失败媒体状态或错误曝光编号可能继承 verify | 验证器重新计算报告，并核对完整时钟、状态、曝光编号、输入与引擎 |
