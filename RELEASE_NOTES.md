# HeiGe-Video v3.0.0-rc.1

## 中文

这次升级加入五支全新原创视频、完整源码和复现指南：夜航、SPECTRA、归岸、38 微秒、拆开平均数。README 以五支成片为入口，旧版五支样片继续作为回归对照。

创作流程强调持久物体、可见状态变化、关键动作小样和真实 MP4 抽帧复核；运行时加入 Canvas 契约、共享运动工具和切点感知 QA。100 部作品（51 部旧基线重新抽帧检查 + 49 部新增）与 100 个独立仓库的研究通过离线选择器按需读取。

这是预发布候选版。研究和工作流改进不等于模型权重蒸馏；没有低价模型同水平或成本优势的实测结论。两支有声片只做过数值测量、未试听；视觉验收有明确采样范围。完整说明见 README、CHANGELOG 和验证状态。

## English

Five new original films, scene sources and reproduction guides: Night Signal, SPECTRA, Homeward, 38 Microseconds and Unpacking an Average. Five v2 films remain explicitly labelled regression fixtures.

The update adds persistent-object direction, motion proofs, Canvas source contracts, shared motion helpers, decoded MP4 review and an offline selector over 100 videos / 100 repositories. Video research uses bounded decoded sampling: 51 reinspected baseline works and 49 additions.

This is a prerelease candidate, not a trained or distilled model. No controlled lower-cost-model parity, cost advantage, full realtime playback or listening result is claimed. See the repository's changelog and verification status for the exact checks and remaining limits.
