# 莓好一口

原创概念甜品演示。16 秒，30 fps，逻辑画布 720×1280，Root 整体放大到 1080×1920。并无真实商品或商业效果声明。

视觉承诺：同一只香脆锥筒接住香草球，草莓在小碗中混入奶油，形成第二球，再接住薄荷球，巧克力从打开的瓶口落到顶球，最后接住彩糖和完整草莓。结尾仍能看清前三球与原锥筒的身份。

结束构图：锥筒 tip 在 y1040 左右，三球纵向叠放，薄荷球上保留真实淋涂边缘、彩糖和红草莓。小确认章停在右侧 y754。最后 1.5 秒停止运动。标题与主体保持分区，顶部约 y64 至320，物体主要 y350 至1080，底部署名 y1120。

## 视觉原则

1. boing-candy 的棉粉画布、泡泡糖粉主角、薄荷和柠檬辅助色搭配葡萄墨文字。
2. 使用原生中文 CaseDisplay 与 CaseSans 的 400 字重，禁用伪粗体，并保留中文系统兜底。
3. 锥筒有真实三角轮廓和交叉华夫纹，冰淇淋球有独立持久身份、波浪边缘与局部高光。
4. 签名落地采用 squash/stretch 和短跳，硬色偏移用于主体深度，不依赖发光或模糊动画。
5. 每次动作用物体改变作为结果，标题说明动作，不能以标题变化代替动作。

## 材质和对象

全片为原创 SVG。草莓有莓籽、绿叶和不对称轮廓。香草、草莓、薄荷三球保持独立 data-object-id。锥筒交叉纹被剪裁在同一锥形内。巧克力增长剪裁与冰淇淋轮廓二次相交，保留不同长度的圆钝滴落。彩糖位置通过固定 index 计算，纹理不使用随机数。
