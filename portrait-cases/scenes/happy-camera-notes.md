# 快乐开拍

原创玩具概念短片。画布 720×1280，30 fps，共 480 帧。最终渲染为 1080×1920。

视觉承诺：同一台钴蓝玩具拍立得完成拨动旋钮、镜头伸出、快门按下、照片连续吐出和照片显影。照片里明确保留开场出现的小花与太阳，观众看见实际操作改变具体物体。

五条不可违反的原则：

1. 温暖纸面为底，钴蓝为主物体，红黄做结构和动作强调。
2. 相机、照片、徽章具有白色模切边、黑色轮廓、固定硬阴影和轻微倾斜。
3. 相机固定包含机身、实体旋钮、快门、取景窗、三层镜头和出片槽，不能用矩形加圆形代替完成态。
4. 顶部文案与主体动作分区。所有实际文字声明 data-readable，字幕没有标点。
5. 同一张纸从出片槽连续吐出，脱离后轻揭纸角。14.5 秒后完全落定。

## 材质与结束构图

相机是有色搪瓷玩具，硬边高光固定在表面。镜头由三个有厚度的环组成，取景窗与快门分开。照片是白色厚纸，独立影像区与留白题字区明确。最后照片位于左前景，相机位于右上方，收藏章位于右下方，留出顶部完整标题与底部署名。

所有 SVG 与动作均为本项目原创，未使用外部图像。字体由共享 Root 管理，配乐由独立原创音轨按上述 cue 编排。本文件只记录创作实现，不代表完整观看与听审通过。
