# 咖啡醒醒

原创概念咖啡演示。16 秒，30 fps，逻辑画布 720×1280，Root 整体放大到 1080×1920。没有品牌商品、效率或健康声明。

视觉承诺：同一只瓷杯来到咖啡机下，手柄锁入后双股萃取落杯，杯子前移放大，奶壶倾斜，牛奶沿真实壶嘴进入杯面，奶涡收成叶形拉花，最后温暖蒸汽升起。

结束构图：放大的瓷杯在 x360、y786，奶咖与完整叶形拉花清晰可辨。杯托和杯柄保留真实层次，三条蒸汽停在杯上。左上留下不规则餐巾纸圈和「慢慢来」注记。最后 1.5 秒全部停止运动。

## 视觉原则

1. coffee-house 的暖纸色、奶泡白承载画面，深烘焙色用于设备轮廓和阅读。
2. 焦糖用于萃取液、暖色小标记与手绘圈，不作为正文色。
3. 文字使用本轮已认可的原生中文 CaseDisplay 与 CaseSans，400 字重，不合成粗体，保留中文系统兜底。
4. 复现不圆咖啡渍和未完全闭合的餐巾纸圈签名，杯子有瓷面高光和暖色阴影。
5. 声音和运动围绕锁手柄、萃取、倒奶、拉花等具体操作，奶涡和叶片是随同一输入逐步形成的结果。

## 材质和对象

原创 SVG 咖啡机带金属工作台、滴水栅格、状态灯、压力表、蒸汽管和可锁入的 portafilter。双股萃取由手柄底部进入杯面。杯体与杯柄、杯托和杯液分别绘制，但保持 coffee-porcelain-cup 身份。杯面在椭圆剪裁内完成浓缩液、奶涡和叶片拉花的逐步变化。奶壶采用同一倾角求出的壶嘴坐标作为倒奶路径入口。全片依据 frame/fps，没有 CSS 时间动画或随机纹理。
