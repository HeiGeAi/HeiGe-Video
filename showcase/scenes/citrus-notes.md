# 柠檬汽水

原创概念广告，2026-10-12。固定 16 秒、30 fps、480 帧。组件导出 `Citrus: React.FC<{portrait: boolean}>`，横版 1280×720，竖版 720×1280。音轨、字体与最终编码由 showcase 入口统一提供，本场景不加载外部资源，不挂 Audio。

## Treatment

一只泡糖粉汽水罐从上方落下，压扁、伸展并稳稳落地。柠檬瓣被两只糖果色小手挤压，汁液沿可见路径进入同一只罐，黄色液体带随之抬升。拉环打开，液体与气泡从开口喷起，原汽水罐跳离地面，再次着地，保持同一轮廓、标签与柠檬徽章。棉粉、泡糖、薄荷、柠檬色场改变节奏，产品仍在同一空间。最后回到「快乐开罐」，原罐压缩蓄力，从原开口排出最后一口泡沫，余压带出一次短跃。14 秒落地触发标签压印回弹，14.5 秒后完全停止动作，留下 1.5 秒完整结束构图。

产品、口味和品牌名均为虚构概念，没有营养、销量、效果或真实商品主张。全片保留醒目的「原创概念广告」。这是一则玩味的视觉概念，不把挤汁装罐描绘为实际工业生产流程。

## 五条设计原则

1. 使用 boing-candy 的棉粉 `#FFF6FB`、葡萄 `#2E1A47`、泡糖 `#FF5CA8`、薄荷 `#33D9B2`、柠檬 `#FFD836`。葡萄色承担所有文字阅读，亮色字不以白色作正文。
2. 中文展示使用 `CandyDisplay, PingFang SC, sans-serif`，原生 weight 400，关闭 fontSynthesis。正文和小 metadata 使用 `VideoSans`，重要文字和罐身文字都有 `data-readable="true"`。
3. 原创罐体有立体轮廓、拉环、接汁开口、柠檬徽章与固定标签。背景变化、喷起、跳跃期间都保留同一对象身份。
4. 复现 Landing Boing 的压扁、回弹、落稳。立体感使用不带模糊的硬偏移实色，不用辉光、模糊阴影或外部素材遮盖动作。
5. 横版把文字放左侧，产品置右侧；竖版把阅读放上方，产品置中下方。每个时间段只有一个主动作，不使用标题加三张卡片。

## 动作与音乐 cue

配乐约定为 120 BPM、4/4、8 小节、16 秒。整拍为 0.5 秒，半拍为 0.25 秒。
