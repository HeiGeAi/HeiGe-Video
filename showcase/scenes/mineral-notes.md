# 花开有声

16 秒原创矿彩动画。30fps，共 480 帧。横版 1280×720，竖版 720×1280。音乐由公共入口提供，组件不含音频、不加载外部资源。

## Treatment

一粒朱砂种子落在暖纸上。石绿引线先画出呼吸与方向，种子破土，枝叶在半拍之间轮番舒展。莲花不是一张插画整体放大。十二片原生 SVG 花瓣分别长出、展开、落定，石青的外瓣、石绿的中瓣、朱砂的内瓣形成真实叠层。盛开后的同一朵花转为放射花心，八枚矿彩叶片沿节拍汇入外缘，偏轴的方形藻井逐层收拢。最后保留完整纹样，让「花开有声」和品牌有清楚的阅读时间。

这是原创植物与几何动画，采用矿彩视觉语言。没有使用敦煌原壁画、馆藏素材或受限制资产，不声称真实敦煌复原。所有 SVG 路径、花瓣、枝叶与印记均在本组件内原创绘制。

## 风格适配

采用 HeiGe Design 的 `dunhuang-mineral`。已读取 `DESIGN.md`、`exports/compact.md` 和 `exports/variables.css`。

- 主画布始终为 `#ece1cb`，浅纸层为 `#f4ebd8`。拒绝暗底切场。
- 石青 `#2e6b8f` 承担外层花瓣与藻井结构；石绿 `#4a8b6f` 承担枝叶、引线与中层；朱砂 `#c8483a` 承担种子、花心与小印记；土金 `#b08d3e` 只作纹路、镶线与花瓣小层，不作纸上的正文。
- 书法标题使用根入口加载的 `SerifDisplay`（Ma Shan Zheng），正文使用 `VideoSans`。中文 fallback 明确为中文楷体、宋体或黑体，字重为 400，禁用字体伪合成。
- 只有一条贯穿的飞天引线。两道同路径矿彩线属于同一条线的边缘与主体，不是两条独立装饰轨迹。
- 签名时刻为偏轴藻井。三个方形矿彩层、金色镶线与莲花核心共同完成结果，不用空环圆圈或均分卡片。
- 纸纹为静态重复的低透明细点与短线，矿彩中保留细小颗粒。不使用辉光、滤镜、动态粒子或随机噪声。
- 原设定集的静态、慢呼吸规则在本次动画任务中改为明确的成长动作。坚持实体层叠与哑光质感，动作服从 120BPM，不把等待当作东方气质。

## 主动作时间表

120BPM，每拍 0.5 秒，8 小节合计 16 秒。事件起点落在 0.25 秒或 0.5 秒网格。帧驱动的连续补间照顾 30fps 半帧节拍，不把音乐时间取整为整帧。

| 时间 | 主动作 | 准备、冲击与反应 |
| :--- | :--- | :--- |
| 0 至 0.5 秒 | 种子轻轻落定，开场已可读 | 纸上已有朱砂种子，种子发生小幅压缩与回弹。无空白等待。 |
| 0 至 1.5 秒 | 单条飞天引线画出 | 线从暖纸边缘贯穿主体，随后保留。 |
| 0.5 至 2 秒 | 萌芽向上拉出石绿主茎 | 实际端点从种子位置上升，至 2 秒长出最终高度的 64％。种子仍留在根部，身份不替换。 |
| 0.75、1.5、3、4 秒 | 四片枝叶交替展开 | 第一片叶在 0.75 秒启动，至 1.4 秒展开；第二片叶在 1.5 秒启动。左右交替，从茎部伸向外侧，不整株机械放大。 |
| 2 至 5.5 秒 | 主茎继续伸长 | 从已可见的幼苗伸到原定花心位置，后段花与纹样布局不变。 |
| 5.25 至 6 秒 | 朱砂花苞形成 | 先出现紧实花心，准备盛开。 |
| 5.75 至 9.25 秒 | 十二片莲瓣逐片展开 | 每片间隔 0.25 秒，外瓣先开，内瓣随后，短促舒展后落定。 |
| 9.5 至 12 秒 | 引线与花心方向转向纹样 | 引线形状连续改变，莲瓣从向上的花形转向放射花心。 |
| 10.5 至 12 秒 | 同一花心汇成放射纹样 | 株茎退场，花心位置与瓣面连续过渡，不硬切成另一张图。 |
| 11 至 13.25 秒 | 八枚矿彩叶片汇聚至外缘 | 每 0.25 秒接入一枚，形成矿彩秩序。 |
| 11.5、12、12.5 秒 | 三层偏轴藻井收拢 | 石青、石绿、土金依次收拢，非居中。 |
| 12.5 至 13.25 秒 | 金色镶线形成 | 线连接矿彩方层，得到完整纹样。 |
| 13.5 至 14.5 秒 | 朱砂小镶点落定 | 同一纹样完成最后细节，不增加多余装饰场景。 |
| 14.5 至 16 秒 | 标题与品牌落款 | 至 14.75 秒品牌完整可见，末帧保留纹样与全部品牌。 |
